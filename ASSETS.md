# Asset policy

The AGPL-3.0 license in this repository applies to source code unless a file states otherwise. It does not relicense third-party media.

The public repository intentionally excludes:

- commercial or copyrighted music and audio recordings;
- personal and celebrity portraits;
- Android signing keys and release packages;
- editable CraftPix source packs and generated atlases derived from them;
- production player, account, clan, moderation and feedback data.

To run a customized build, provide your own licensed replacements and update the relevant asset mappings. Do not submit assets unless you own them or their license explicitly permits redistribution in a public source repository.

DarkVell names, logos and branding are not granted for use by the AGPL source-code license unless the project owner gives separate permission.
